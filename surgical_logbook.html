      How cross-device sync works
      This logbook is a single HTML file. When opened directly from your computer, each device has its own isolated local storage — they cannot see each other. To sync across devices you need to either:
      ① Host it online (GitHub Pages — free, permanent URL, recommended) and connect to Google Sheets, or
      ② Export → transfer the file → Import on the other device as a manual backup method.

      ① Host on GitHub Pages RECOMMENDED

      GitHub Pages gives your logbook a permanent https:// URL. Open that URL on any device — phone, tablet, laptop — and all data syncs through Google Sheets.

      1. Create a free account at github.com if you don't have one.
      2. Click + (top right) → New repository. Name it surgical-logbook. Set it to Public. Click Create repository.
      3. On the next page click uploading an existing file → drag and drop this HTML file → click Commit changes.
      4. Go to Settings → Pages (left sidebar) → under Source select Deploy from branch → branch: main → folder: / (root) → click Save.
      5. Wait ~60 seconds. Your logbook will be live at:
        https://YOUR-USERNAME.github.io/surgical-logbook/surgical_logbook.html
      6. Open that URL on every device. Bookmark it. This is now your logbook URL.
      After hosting: set up Google Sheets sync below, then use Push after adding entries and Pull when opening on a new device to get the latest data.

      ② Google Sheets Sync

      Stores all your data in a Google Sheet in your Drive. Works best when the logbook is hosted online (Option ①). Also works locally as a manual backup — push before closing, pull after opening.

      Step A — Deploy the Apps Script
      1. Open sheets.new → name the sheet Surgical Logbook.
      2. Extensions → Apps Script → select all existing code → delete it.
      3. Click ⎘ Copy Script below → click inside the green box → Ctrl+A then Ctrl+C → paste into Apps Script → Ctrl+S to save.
      4. Check the left panel shows three functions: doGet, doPost, out. If not, the paste failed — try again.
      5. Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy → Authorise access → pick your Google account → Allow.
      6. Copy the URL ending in /exec.

      ✓ Click inside → Ctrl+A → Ctrl+C → paste into Apps Script

      Step B — Verify & Connect

      Paste your /exec URL below. Click ↗ Test in Tab — you should see {"ok":true,"msg":"pong"}. Then click Save & Connect.

      Step C — Push & Pull

      Push after adding entries — uploads your data to Google Sheets.
      Pull → New Tab opens a page with your cloud data. Click Copy All Data there, come back here, paste and import. This works even from a local file.

      In the tab that opened: click Copy All Data, then paste it below and click Paste & Import.

      ③ Manual Export / Import WORKS OFFLINE

      Export all your data as a .json file. Transfer it to another device (WhatsApp, email, USB) and import it there. Also useful as a regular backup.
